Configuration de l’administration requise

Cette administration fonctionne après le déploiement Cloudflare Pages et la configuration des variables secrètes. En ouvrant le fichier localement, utilisez les étapes « Administration hébergée sans frais » du README pour la mettre en ligne.

Connexion de la cliente

Un seul mot de passe administrateur est autorisé. Il n’y a pas d’inscription pour les visiteurs.
